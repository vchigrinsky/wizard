# wizard — LOG

## Entrypoint

Репозиторий материалов Telegram-канала [vuutya](https://t.me/vuutya): лонгриды про прикладные ИТ-штуки (VPN, сети, саморазвёрнутые сервисы) и project site GitHub Pages.

Публичный сайт: [vchigrinsky.github.io/wizard](https://vchigrinsky.github.io/wizard/).  
Репозиторий: [github.com/vchigrinsky/wizard](https://github.com/vchigrinsky/wizard).  
Единственная рабочая ветка: `master`.

Форматы материалов: веб-страница (Pages), исходный Markdown, при необходимости PDF.

### Общие правила

- Всё на русском: общение с пользователем, Markdown-документы, сообщения коммитов.
- Работаем только в `master`: коммит и сразу push в `origin/master`. Отдельное разрешение на это не нужно. Отдельные ветки — только если пользователь явно попросил.
- Когда пользователь говорит «сохраняемся» (или близкое по смыслу): обновить этот `LOG.md` (проверить текущую дату, дописать историю в блок нужной даты сверху, актуализировать current state), затем коммит и push.
- Новые правила в шапку лога добавлять только по явной отмашке пользователя. Самостоятельно можно править только current state и исторические блоки.
- При любых правках md-артефактов статей (`01-setup-vpn.md`, `02-connect-vpn.md` и любых будущих) всегда и безусловно: (1) зеркально обновить одноимённые файлы в `data/` — без навигационных ссылок «← Все материалы» / «Скачать …»; (2) пересобрать PDF в `data/` через `mdpdf`. Страницы на сайте и файлы для скачивания должны оставаться синхронизированы.
